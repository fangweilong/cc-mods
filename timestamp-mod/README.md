# timestamp-mod

加载后为用户消息、工具调用和每段回答补充时间与用量：

- 用户消息上方显示发送时间。
- 每个工具调用在工具块顶部用一行显示 `开始 → 结束 · 耗时`（执行中显示 `→ running`）；默认还会追加该工具所属模型请求的 Token 用量（`↑12.0k ↓1.2k`，同一请求内的多个工具共享这组值）。
- 每段回答的首个文本块上方显示该模型请求的开始/结束时间、耗时、Token 用量与输出速度：`[12:55:10] → [12:55:11] · 1.0s · ↑10 ↓100 · ⚡ 100.0 tok/s`。生成中先显示 `[开始] → running · ⚡ ≈42.0 tok/s`（估算值，黄色），请求结束后补齐结束时间、耗时、Token 与精确 TPS。

为确保折叠的工具组也能逐项显示时间，启用时会展开 `ToolGroup`。该 Mod 不修改模型收到的 Prompt、用户消息内容、助手文本、工具参数或工具结果。

通过 `/my-cc-mods-config` 配置启用开关、TPS/Token 显示开关和时间格式规则。

配置保存在 `~/.config/my-cc-mods/config.json` 的 `timestamp` 段：`enabled`、`tps`、`format`。支持占位符：`YYYY`、`YY`、`MM`、`DD`、`HH`、`mm`、`ss`、`SSS`。
