# timestamp-mod

加载后为用户消息、工具调用和每段回答补充时间与用量：

- 用户消息上方显示发送时间。
- 每个工具调用在工具块下方缩进显示 `⏱ 工具名 · 开始 → 结束 · 耗时`（执行中显示 `→ running`），明确时间所属调用；默认还会追加该工具所属模型请求的 Token 用量（`↑12.0k ↓1.2k`，同一请求内的多个工具共享这组值）。
- 每段回答的首个文本块上方显示该模型请求的开始/结束时间、耗时、Token 用量与输出速度：`[12:55:10] → [12:55:11] · 1.0s · ↑10 ↓100 · ⚡ 100.0 tok/s`。生成中先显示 `[开始] → running · ⚡ ≈42.0 tok/s`（估算值，黄色），请求结束后补齐结束时间、耗时、Token 与精确 TPS。

默认保留原生工具组折叠：折叠时显示原生汇总行，展开后逐项显示工具时间。可独立开启“自动展开工具组”（`autoExpandToolGroups`，默认 `false`），恢复始终逐项显示时间的行为；该开关仅在时间显示启用时生效，与 TPS/Token 显示开关无关。旧配置无需迁移，未设置时不自动展开。该 Mod 不修改模型收到的 Prompt、用户消息内容、助手文本、工具参数或工具结果。

工具计时与所属请求用量保存在宿主的会话状态中，Mod 热重载后仍可读取，展开旧工具时不会因为模块重新加载而丢失。只记录启用期间实际观察到的调用；旧版本热重载时已丢失的计时、启用前的调用以及重启或恢复会话前的历史记录不会补算，也不会用当前时间冒充工具执行时间。

通过 `/my-cc-mods-config` 配置启用开关、TPS/Token 显示开关、自动展开工具组开关和时间格式规则。

配置保存在 `~/.config/my-cc-mods/config.json` 的 `timestamp` 段：`enabled`、`tps`、`autoExpandToolGroups`、`format`。支持占位符：`YYYY`、`YY`、`MM`、`DD`、`HH`、`mm`、`ss`、`SSS`。
